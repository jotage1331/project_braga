# Landing Page — Consultoria de Investimentos

Landing page institucional e funil de captação de leads para consultor de investimentos vinculado à Varos.

## Tecnologias
- HTML5 semântico
- CSS3 puro moderno (Grid, Flexbox, Custom Properties)
- JavaScript vanilla (ES6+)
- Hospedagem: GitHub Pages
- Captação de leads: Google Apps Script + Google Sheets

## Como rodar localmente
Na raiz do projeto, execute:

\`\`\`bash
python3 -m http.server 8000
\`\`\`

Depois acesse `http://localhost:8000` no navegador.
